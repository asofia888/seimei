# 熊崎式 姓名判断

旧字体（康熙字典体）の画数と陰陽五行にもとづく、熊崎式（五格剖象法）の姓名判断アプリです。
**`index.html` ひとつで動く単一ファイル構成**のため、サーバーもインストールも不要です。

## 特徴

- **五格**（天格・人格・地格・外格・総格）と**八十一数理**による吉凶判定（大吉／吉／半吉／半凶／凶の五段階。81数それぞれに**数理名**〔吉祥運・頭領運・福寿運など〕と総合解説＋仕事・金運・対人・健康・心得の詳細解説を収録）
- **性別（任意）による判定**——女性の場合、頭領数（21・23・33・39）と活動数（29）は「強すぎて凶に転じる」とする熊崎式の伝統則を判定・総評に反映（未指定なら据え置きで参考注記を表示）
- 一字姓・一字名の**霊数**に対応（天格・地格・外格の計算にのみ加算し、総格には加えない方式）
- **陰陽配列**の判定（純陽・純陰、二分、挟み、片寄り、調和）
- **三才五行**の判定（天・人・地の下一桁を五行に配し、成功運・基礎運の相生相剋を図解）
- 重み付きの**総評**を自動生成
- 伝統的な鑑定書風の**命式図**（縦書きレイアウト）と**印刷機能**

## 画数の数え方（熊崎式）

| 規則 | 例 |
|---|---|
| 旧字体（康熙字典体）に直して数える（291組） | 沢→澤(17)、広→廣(15)、恵→惠(12)、辺→邊(22)、桧→檜(17)、鴎→鷗(22) |
| 部首は元の文字の画数（約3,000字を自動補正） | さんずい=水(4)、くさかんむり=艸(6)、しんにょう=辵(7)、りっしんべん=心(4)、こざとへん=阜(8)、おおざと=邑(7)、たまへん=玉(5) |
| 漢数字は数意 | 四=4画、五=5画、十=10画 |
| 異体字は標準字体と同字扱い | 髙→高(10)、𠮷→吉(6) |
| その他 | 々・ゝ・ヽ＝直前の字と同数、ゞ・ヾ＝直前＋2（濁点）、〆=2画、ひらがな・カタカナ・長音符に対応（半角カナは全角に正規化） |

収録は約13,300字。数え方には流派差があるため、**文字ごとの画数はカード上でその場で手修正**でき、
設定パネルで「旧字体変換」「部首元字」「数意」の各方式を個別にオン／オフできます（設定はブラウザに記憶されます）。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. 姓と名を入力すると文字ごとの画数カードが表示される（性別は任意。選ぶと頭領数・活動数の判定に反映）
3. 「鑑定」ボタンで命式図・五格・陰陽・三才・総評を表示
4. 必要に応じて「鑑定書を印刷」

## GitHub Pages で公開する

1. このリポジトリを GitHub にアップロードする
2. リポジトリの **Settings → Pages** を開く
3. **Source** で `Deploy from a branch`、Branch に `main` / `(root)` を選んで保存
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

`index.html` という名前のままにしておけば、URLの末尾にファイル名を付けずにアクセスできます。

## 再ビルド（開発者向け）

画数辞書や判定ロジックを変更したい場合は `build/` ディレクトリのソースから再生成できます。
手順は [`build/README.md`](build/README.md) を参照してください（Python 3 と Node.js を使用）。
