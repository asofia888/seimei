# 検証

## 手順
1. 依頼の「必須の要件」「制約・作業範囲」「完成の定義」を確認する。
   渡されていなければ、成果物から逆算せず「要件が未提示」と報告する。
2. 判定軸が必要な作業では `rubric.md` を読む。
3. 一段目（粗探し）：自信のないもの・軽微なものも含め、見つけた問題をすべて挙げる。
   この段階では重要度で絞らない。「重大なものだけ」と自分に課さないこと。
4. 実行・確認できるものは実際に実行する。推測で「動くはず」と書かない。
   確認できなかった項目は「未検証」と明記する。
5. 二段目（選別）：重要度順に並べ、重大度（高・中・低）と修正方針を一行ずつ添える。
6. 必須の要件を一つずつ ○× で照合した表を最後に付ける。

## しないこと
- 成果物の書き換え（修正は本体の仕事）
- 社交辞令。問題がなければ「指摘なし」とだけ書く
