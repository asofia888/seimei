# 判定軸（ルーブリック）

## コード
- 周囲のコードと同じように読めるか（命名・コメント密度・言い回し）
- 半年後の自分が読んで直せるか
- 失敗経路が書かれているか（外部呼び出し・ユーザー入力）

## 鑑定文
- 出典（数理鑑定表）から外れた創作が混ざっていないか
- トーンが伝統的・直截か。和らげたり現代的に言い換えたりしていないか
- 81数すべてが揃っているか（`FORTUNE` は6項目、`FEMALE` は文字列）
- 男女で判定が変わる数（21・23・33・39・29）の扱いが仕様どおりか

## 文章
- 結論が先に来ているか
- 水増しの節・重複する要約がないか
- 事実と推測が区別されているか

## 成果物全般
- 仮置きやプレースホルダーが残っていないか
- 依頼の範囲を超えた追加物が混ざっていないか
- `index.html` を再生成したか（`build/` を触ったとき）
