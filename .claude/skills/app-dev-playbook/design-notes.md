# 視覚的な方向性（参照ファイル）

伝統的な鑑定書の見た目。既存の `template.html` に合わせる。

## 配色（実際に使っている値）
- 地：生成り（#fdf6ee）／カード面は白に近い生成り（#fffdf7）
- 罫線：薄い金茶（#e9e0cb・#dccfb2・#b9ab90）
- 文字：焦茶（#6a6154・#7d7259）
- 主色：金（#96793a・#b8862d）。見出しと強調に使う
- 差し色：朱（#a63a2b）。判子・凶の表示など、一点だけ
- 五行・吉凶の色（#3f6b4f・#31465e・#9e596d など）は既存の割り当てを崩さない

## 書体
- 見出し・命式図：Shippori Mincho B1
- 本文：Shippori Mincho（フォールバックは Hiragino Mincho ProN → Yu Mincho → serif）
- ゴシックは使わない。全面的に明朝で組む

## 決めごと
- 影は薄く。角丸は小さく
- 命式図は縦書き。横書きに直さない
- 印刷（鑑定書）を必ず確認する。画面用の背景色は印刷で飛ぶ前提で組む
