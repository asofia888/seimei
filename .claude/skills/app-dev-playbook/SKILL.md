# 単一HTMLアプリの流儀

一般的な作り方は書きません。このプロジェクト固有の決めごとだけです。

## 決めごと
- **成果物は単一HTML。ただし手書きではなくビルド生成。**編集は `build/` 側
  （`template.html` / `calc.js` / `ui.js`）で行い、`python3 build_app.py` で
  `index.html` を作り直す。詳細は CLAUDE.md の落とし穴を参照。
- 外部依存は Google Fonts（Shippori Mincho / B1）だけ。それ以外の CDN は足さない。
- ロジックは `calc.js`、描画は `ui.js`、体裁は `template.html`。境界をまたがない。
- コメントは日本語。密度は周囲のコードに合わせる。
- 鑑定文の出典は数理鑑定表。トーンは伝統的・直截で、和らげたり現代的に言い換えたりしない。

## 完成の定義
- 必須の要件をすべて満たしている
- `node test.js` が通る（鑑定ロジック・鑑定文を触ったときは必須）
- `index.html` を再生成し、ブラウザ単体で動く
- スマホ表示と印刷（鑑定書）で崩れない
- 仮置きやプレースホルダーが残っていない

視覚的な方向性が要るときは `design-notes.md` を読む。
