# 流儀ノートの更新

Claude は作業とユーザーに関連する記憶を自動で保存するようになりました。
このスキルが扱うのは、自動では拾いにくい **ユーザー固有の流儀・判断基準** だけです。

## 書くもの
- 好みの判断基準（何を良しとするか）
- 繰り返し表明された方針
- 「こうしてほしい」と明示的に言われたこと

## 書かないもの
- 作業の経過、進捗、やったことの記録
- リポジトリを見れば分かること
- 一度きりの指示

## 書式
1項目＝1教訓。冒頭に一行要約。
既存の項目と重複するなら、追加ではなく更新する。誤りと分かった項目は削除する。

## 手順
LESSONS.md を読み、追記・更新・削除を行い、変更点を一覧で報告する。
